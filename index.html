Takip — Gizlilik Politikası

Son güncelleme: 30 Ağustos 2026

Takip, verilerinizi geliştiriciye ya da üçüncü taraf bir sunucuya göndermez. Uygulamanın kendi sunucusu yoktur.

GitHub erişimi

Uygulama, sizin sağladığınız kişisel erişim anahtarıyla (token) kendi GitHub depolarınıza bağlanır. Bütün ağ trafiği doğrudan cihazınız ile GitHub API arasındadır.

Token saklama

Anahtarınız yalnız cihazınızın güvenli deposunda (Android Keystore destekli) tutulur; dosyaya, günlüğe ya da başka bir sunucuya yazılmaz. Dışa aktarım yalnız sizin belirlediğiniz parolayla şifrelenmiş yedek olarak yapılır.

Çevrimdışı kopya

Depolarınızın içeriği, çevrimdışı okuma için yalnız cihazınızda önbelleğe alınır ve uygulama içinden silinebilir.

Toplanan veri: yok

Analitik, reklam kimliği, kilitlenme raporu dahil hiçbir veri toplanmaz.

Hesap gerektirmez

Uygulama hesabı yoktur; silinecek sunucu verisi de yoktur — uygulamayı kaldırmak cihazdaki her şeyi kaldırır. GitHub'ın kendi veri işleme koşulları kendi hesabınız için geçerlidir.

Takip — Privacy Policy

Last updated: August 30, 2026

Takip does not send your data to the developer or to any third-party server. The app has no server of its own.

GitHub access

The app connects to your own GitHub repositories using the personal access token you provide. All network traffic goes directly between your device and the GitHub API.

Token storage

Your token is kept only in your device's secure storage (backed by Android Keystore); it is never written to a file, a log, or any server. Export happens only as a backup encrypted with a password you choose.

Offline copy

Repository content is cached only on your device for offline reading and can be cleared from within the app.

Data collected: none

No analytics, no advertising ID, no crash reports — nothing is collected.

No account

There is no app account and no server-side data to delete — uninstalling the app removes everything on the device. GitHub's own data terms apply to your GitHub account.
